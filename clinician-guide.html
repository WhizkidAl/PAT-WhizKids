Set up a PAT Base

Use the shared PAT application for each family. The family’s configuration and records stay private; a new family does not need a copied public website.

1 · Prepare the private workspace

Create the participant in the dedicated PAT project and grant named parent and child/tablet accounts the appropriate roles. Do not use the clinician account on the child’s tablet. Keep identifiable configuration, avatar, manual and records in the private workspace. Keep formal clinical documents in your clinical record system.

2 · Start with the generic template

Use the current shared app, blank records, generic starter links and no participant-specific credentials. Set the participant display name, parent help recipient, calendar links, character and manual. Review every inherited link before handover. The generic template and individual workspaces use the same application release.

3 · Explain the four sections

  • My day: calendar and routines.
  • My practice: agreed practice and therapy/school resources.
  • Explore: interests, discovery and optional websites.
  • Make something: creative tools and saved creations.

Keep these sections and Whiz Kids identity fixed. Family setup can change activity links, pictures, availability, colours and the child’s start-screen character. The installed shortcut retains the shared snake icon.

4 · Agree the plan with the parent

Open Weekly practice plan. Choose session minutes in 15-minute steps and sessions per week. The suggested ordinary allowance is minutes ÷ 15 × sessions; the parent can set another whole allowance. Three 30-minute sessions suggests six coins. Choose which provider tasks are eligible using positive weekly frequencies. New providers do not automatically increase the allowance.

Save the minute plan explicitly. The previous plan remains until activation; existing rewards are preserved. Once a week has recorded work, changes start next Monday. One coin is earned per full 15 minutes in a checked session, within the weekly cap. Shorter sessions remain recorded. Two separate weekly bonuses require completed criteria and parent approval. Routine ticks do not add practice coins under this plan.

5 · Give the parent the reusable pack

Use the paper device note, sectioned parent guide and provider pack and parent invitation. Invitations are sent by the parent. Resource links can be maintained by the provider and updated by the parent without routing each change through you.

6 · Check handover

On the actual child account, check four sections, each chosen resource, calendar symbols, a telehealth test join, Help delivery and save/reopen. On the parent account check PIN, settings and approval. Do not create fictional clinical records to test a live workspace. Keep a private backup before changing devices.

7 · Updates and ongoing maintenance

Publish shared code updates once. The installed PAT app checks for releases online and applies them on Home after saving. It waits while an activity, recording or dialog is open. Parent instructions cover the same process at home and school. External subscriptions, app permissions and calendar sharing are separate.
