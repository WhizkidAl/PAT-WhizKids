One link. A clear task.
A shared plan.

PAT means Portable Access to Therapy. PAT Base gives the child one place to open agreed activities, check routines and appointments, ask for help and report how practice went. The family sets the practice allowance and checks completed work.

The PAT hub is provided without a software subscription fee. Provider services and outside subscriptions keep their own costs and terms. There is no need to move your clinical records into PAT.

1 · Send the parent these details

ResourceA stable HTTPS link, title and suitable picture/icon.
TaskA short instruction, what finished means, suggested minutes and sessions per week, support needed and review date.
AccessWhich family account needs access, any subscription needed and who maintains the resource. Send passwords separately through your agreed secure process.

Keep updating resources behind the same link. The parent can replace a link or mark it Not ready in Family setup. Routine resource changes do not need to come back to Alexandra.

2 · Keep resources where you maintain them

  • Your approved portal or subscription: supply the direct activity link and the correct sign-in route.
  • OneDrive / SharePoint or Google Drive: use a dedicated family folder and share with named accounts, normally as viewers. Test it using the intended account. Folder sharing can reveal everything inside that folder.
  • Canva: supply a view link for instructions or an agreed template link for creative work. Check permissions and licensing; not every Canva plan or external service is free.
  • GitHub Pages: a free public hosting option for generic HTML activities and worksheets you have permission to publish. It is not private clinical storage.
GitHub Pages: a simple starting route
  1. Create a GitHub account and a new public repository for generic resources.
  2. Use Add file → Upload files. Upload your HTML as index.html, plus its images and worksheets. Commit the files.
  3. Open Settings → Pages. Choose Deploy from a branch, then main and /(root), and Save.
  4. Open the published HTTPS address, test every button on a tablet, then give the parent the link.
  5. Replace files in the same repository to update them. Keep the address stable.

Public means publicly accessible. Do not upload names, identifiable avatars, therapy notes, recordings, passwords or copyrighted subscription worksheets. HTML can run here; server-side applications cannot. For private or identifiable material, use your approved restricted platform.

3 · Use the calendar code

Send calendar invitations to the parent and add the child’s Google address as an attendee. An email CC alone is not a calendar invitation. The parent checks that the first invitation appears and accepts it if needed.

💼 In person“💼 Speech — provider” + address, date, start/end and timezone.
☁️ Telehealth“☁️ OT — provider” + Join appointment: direct meeting link first in the description. Add platform, ID/passcode and adult support underneath.
🔔 Reminder“🔔 Practice — choose an activity”. This is a prompt, not an appointment or proof of practice.

Send changes and cancellations through the same calendar event. Keep appointment titles brief and avoid clinical detail.

4 · Connect a task to coins

Tell the parent the task, finish criteria and recommended time. In Family setup they add the activity and a positive weekly frequency, then save the overall Weekly practice plan. PAT calculates one coin per full 15 minutes of parent-checked practice, up to that week’s allowance. A 30-minute session can earn two. Opening an app does not earn coins.

At week end, after completing the planned sessions and allowance, the child can request one completion bonus and one further bonus for a separate extra session after finishing the plan. Both need parent approval. The parent keeps the overall workload appropriate; adding a provider does not automatically increase it. Providers do not need to code a coin connection or send repeated approval requests to Alexandra.

5 · Roles stay clear

Providers maintain their resources and recommendations. Parents choose links, agree the plan, manage device access and approve coins. The child records practice and asks for help. This email gives no access to PAT records, calendars or accounts; named access is arranged separately.
